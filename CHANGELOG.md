## 0.12.0

### Minor Changes

- 6460dcd: Admin › Upload: upload movies and episodes from the app into any movie or series folder on the server's disks. Browse into a folder or make one, pick files, and follow each one's progress, speed and time left. An upload that stopped carries on when the same file is picked again, and the server adds the new files to the library when they're done.
