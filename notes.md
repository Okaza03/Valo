# Valo v0.8.6

New arrivals tell you which seasons came in, and announce a season when it's added to a series you already have.

### New
- **Seasons in new arrivals:** a new series shows the seasons it came with, like Seasons 1–3. When a new season is added to a series you already have, the series shows up in new arrivals again with New: Season 4. On the desktop and the TV app.

### Admin
- **Syncs that report what changed:** on the reference server, Sync movies, Sync series and Sync folders often reported nothing new, because the server had already picked up the new files on its own. They now list everything added or removed since the last sync.
- **Pick the episode for a subtitle:** in the library editor's Subtitles tab, a series has Season and Episode dropdowns instead of a box to type S01E02 in.
- **Downloading a series' subtitle:** Download on a search result now tells the server which episode it's for, so servers no longer answer "Choose an episode".
- **Search collections:** Admin › Collections has a search box that finds a collection by its name or by a title in it.
- **Collections that stay in view:** the list of collections scrolls by itself, and the open collection beside it scrolls separately, so its name and Save button aren't left behind at the top of the page.
- **Movies without a collection:** a button in Admin › Collections lists every movie that isn't in one. Tick one or more, pick a collection (or a new one) and add them in one go.
- **Sort all by release date:** puts the titles of every collection in release order, oldest first, after asking.
