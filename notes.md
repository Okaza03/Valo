# Valo v0.10.1

Fixes for the Admin page's Users section, and Tab moves between fields.

### New
- **Ask a new user for a new password:** Admin › Users › Add a user has **Require to change password on next login**.
- **Tab between fields:** Tab moves to the next text field and Shift+Tab to the previous one, as in a browser form.

### Fixed
- The **⋮** menus in Admin › Users and Admin › Requests open again. Near the bottom of the window they open upward.
