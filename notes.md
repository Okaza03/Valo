# Valo v0.8.11

Movies and series deleted from the server no longer linger in the apps, and New arrivals tells you about them.

### Desktop and TV
- **Removed titles:** New arrivals also lists movies and series taken off the server since you last looked, by name.
- **A fresher library:** the library reloads when you come back to Valo after a minute or more (switching back to the window on desktop, returning to the app on TV), so new and removed titles show up without restarting.

### Admin
- **Syncs reload the library:** every sync on the Dashboard, the Compare dry run included, reloads the library, so titles the server has dropped disappear right away.
