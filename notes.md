# Valo v0.9.10

Signing in to a new server is quicker, and Valo has a website.

### Changed
- **Adding a server:** the server check still runs right after you enter the address. After you sign in, the rest of the check now shows only to admins; everyone else goes straight to the library.

### New
- **Website:** Valo has a home page at https://okaza03.github.io/Valo/ with what it does, downloads for every platform and how to set up a server.
